# Security model

Offline synthetic occupancy teaching tool, not job execution/transport infrastructure. Trust the reviewed interpreter/application; treat input bytes/native values as untrusted for parsing and report integrity. Source-kind/IDs/completion declarations do not establish provenance, authority, work effects or actual processing.

Mitigations: fixed byte/tree/cardinality/Unicode/number bounds; duplicate-key rejection; exact native identity checks before hooks; frozen admitted records; whole structural validation before owned semantic replay; FIFO selection only after free-slot/queue checks; job/slot completion matching; globally unique submitted IDs; independent snapshots; content-free diagnostics and checked complete report size before return/emission. Alias visits count repeatedly and ancestor cycles reject. Reports label effects unmodeled/actual execution unverified.

Postdecode allocation, native caller allocation/concurrent mutation, file/descriptor races, blocking I/O, CPU/RSS deadlines and same-user/OS isolation remain uncontained. Public rendering expects internal trusted reports. Failed stdout can leave irreversible bytes, and stderr may be undeliverable; physical closed-pipe tests do not prove all I/O behavior.

No real threads/queues/jobs/services, blocking producers, live backpressure/fairness, persistence/durability, authenticated completion, retries/redelivery/idempotency/cancellation or actual effect guarantee. A completed model record is not successful real work. Use only invented fixtures; do not add private employer/client evidence or secrets. Manual security review is required before adapting this input handler to real evidence. Finite tests/SAST/self-review are not production certification.

No hosted repository or disclosure endpoint exists; do not publish sensitive reports. Current approval covers local stages only, not repository creation, external services, release, merge or deployment.
